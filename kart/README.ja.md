# 郡中カートラリー

Turbo Kart Rally を郡中プロジェクトの報告ごほうびとして組み込んだ版。
取得元：https://github.com/bridge-mind/turbo-kart-rally
取得コミット：`c52aca3f10c7995884c316810cac6514daa40e9c`
原作の MIT ライセンスは `LICENSE` に保持しています。

## 使い方

1. 報告画面から今日のできたことを報告する。
2. 「報告ごほうびカート・タイムランキング」を開く。
3. レーサーと解放済みのクラスをえらび、レース開始を押す。
4. 1周完走するとタイムを自動保存。同じ応答で50cc・100cc・150ccのランキングを受け取り、自動表示する。
5. ランキングは1日1回・10秒間。時間が来ると報告画面へ自動で戻る。

クラスの解放条件：50ccは最初から、100ccは5チーム、150ccは全11チームのマスター。
マスター数は既存の Users シートの Mastered 列から取得します。
クラスによって全車の最高速度・加速とCPUの難しさが変わります。
1日1回はクラス共通。日本時間の日付で判定し、開始時に消費します。
途中終了・再読み込みでも再挑戦できません。一時停止から再開できます。
操作はキーボード／ゲームパッド。タッチ操作のハンドルはありません。

CPU名は Users シートの他の登録児童から最大7名を選びます。
自分とサンプル登録は除外。人数が足りないときは同じ児童名を使います。
CPUであることを画面に表示し、児童の実際の走行記録とは区別します。
名前はHTMLに埋め込む際にエスケープします。

## 保存とランキング

既存のデータ用スプレッドシートに、最初のレース開始時に `KartRuns` シートを自動作成します。
列は RaceId / UserId / Date / StartedAt / FinishedAt / TimeMs / RequestId / Class / RankingViewedAt / RankingRequestId。
後ろの2列で閲覧開始時刻と再送用IDを保存し、別端末や再読み込みでも1日1回・期限の延長なしをサーバーで検証します。
UserId は既存の公開用ハッシュを使い、本人認証トークンは保存しません。
Class は easy=50cc / normal=100cc / hard=150cc。

クラス別に1人1件の自己ベストを表示し、各クラスの上位10人と自分の順位をまとめて返します。
ロビーの閲覧ボタン・クラス切替・再読み込みボタンは設けず、完走後だけ表示します。
集計は60秒の共有キャッシュを利用し、新しい完走記録をロック内で差分反映します。
保存とランキングを1回の通信にまとめ、送信開始を最大2.5秒分散します。
ロックは100msで取得できなければBUSYを返し、端末側で待ち時間をばらして最大4回試行します。
同タイムは同順位。未完走とCPUはランキングに含みません。
保存に失敗した場合は画面上のボタンで再試行でき、同じブラウザーで次に開いたときも再送します。
同じ保存要求を再送してもランキングの表示期限は延長しません。
利用日・クラス解放・記録の所有者・二重開始と二重保存はサーバーで検証します。
タイムはブラウザーのゲーム内計測です。サーバーでは範囲と開始からの経過時間を検証しますが、
改造クライアントの走行内容そのものを証明する方式ではありません。

## 本番への反映

公開先は既存の GitHub Pages と Apps Script ウェブアプリです。更新には次の両方が必要です。

1. `gas/Code.gs` を既存 Apps Script に同期し、既存ウェブアプリのデプロイを新バージョンに更新する。
2. `web/` 全体を既存 GitHub Pages に反映する。`kart/` も同じオリジンで配信する。

APIのURLを変更する場合は、`web/index.html` と `web/kart/src/reward.js` を両方更新してください。
古いAPIのまま画面だけ更新すると、カート用APIが利用できません。
Three.js は jsDelivr から取得するのでインターネット接続が必要です。
動作検証にはモックAPIを使用し、実データへの試験書き込みは行いません。

手元の既存ソースにマイクラのプレゼント処理は見つかりませんでした。
マスター画面には今回、カートの解放条件・進捗を追加しています。

## 確認

プロジェクトルートで `node --test tests/kart-api.test.cjs`。
GASをインメモリのシートで動かし、実スプレッドシートを変更せずに検証します。

ブラウザー確認は `tests/kart-browser.cjs`。Playwrightを一時フォルダの
`gunpro-kart-qa` にインストールし、`python -m http.server 8087 --directory web`
で配信して実行します。Edgeのヘッドレス実行とモックAPIを使用します。
日本語画面、100cc解放・150ccロック、開始・一時停止、保存1通信での3クラス自動表示、
10秒での自動帰還、同日再入場時にAPIを呼ばないことを確認します。

画面の更新：報告画面は約3分ごと・タブに戻ったときにHTMLの更新を確認します。
入力中は更新案内を出し、それ以外は再読み込みします。ゲーム中の強制更新はしません。
カートのモジュール・CSSはリリース番号付きURLで配信し、入口を再読み込みしたときに新版へ切り替えます。
